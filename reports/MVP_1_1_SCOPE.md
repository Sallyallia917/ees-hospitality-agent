# MVP 1.1

Deterministic intent classification and response routing before RAG.

- Public FAQ: RAG.
- Personal order questions: require verified order context; current version has no booking integration.
- Real-time availability: human verification.
- Transactions: handoff only; no execution.
- Service requests and complaints: handoff only; no ticket creation.
- Safety incidents: highest priority.

No real authentication, PMS/OTA, booking lookup, inventory API, or agent in this version.
